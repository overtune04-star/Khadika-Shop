# Foto produk

Simpan foto produk di folder ini, misalnya `beras-ramos.webp` atau `sabun-mandi.jpg`.

Ukuran yang disarankan sekitar 1000 × 1000 piksel dengan format WebP atau JPG terkompresi. Di [products.js](../products.js), isi properti `image` dengan path relatif, contohnya:

```js
image: "./images/beras-ramos.webp",
```

Untuk foto baru, usahakan latar sederhana dan produk terlihat utuh. Halaman akan menyesuaikan ukuran foto ke kartu produk di desktop maupun HP. Jika gambar belum tersedia atau path-nya salah, emoji produk tetap akan muncul.
